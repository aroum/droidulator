## Highlights

- Added searchable Help and a dedicated units reference with unit symbols, names, aliases, syntax, and examples.
- Unified toolbars, buttons, menus, cards, spacing, and typography across the app, with support for light, dark, and custom themes.
- Made syntax highlighting immediate and incremental. In the 500-line script benchmark, average highlighting work per edit dropped from approximately 159 ms to 4.35 ms on the CI emulator. Device performance may vary.

## Calculator and scripting

- Reworked expression evaluation around a single syntax-tree parser and fixed factorials, logical XOR, comparisons, operator precedence, arrays, ranges, indexing, and parameter scope handling.
- Corrected RKM notation: `4k70`, `4k75`, and `1k50` now evaluate to `4700`, `4750`, and `1500`.
- Improved formula and script argument handling, error recovery, loop and recursion limits, and script error line reporting.
- Expanded GNU Units integration and improved conversion validation and alias handling.
- Preserved full stored result precision when switching REPL display precision from 0 to 12 decimal places.

## Interface and reliability

- Reorganized script editor controls, added cursor line information, and improved autocomplete and keyboard navigation.
- Added optional haptic feedback for toolbar buttons, including DEG/RAD, without feedback on dropdown menus.
- Fixed REPL input focus after submitting commands and improved startup behavior when the welcome message is disabled.
- Moved calculations and persistence off the UI thread and improved session isolation and native string handling.
- Improved draft restoration, session and plot persistence, and handling of damaged saved data.

## Validation and downloads

- Added Android regression tests, native and JNI checks, sanitizer checks, conversion fuzzing, and automated performance reports with Perfetto traces.
- Verified process restoration, upgrades with retained data, and theme, font-size, and screen combinations through device testing.
- APKs are provided exclusively for 64-bit ARM (arm64-v8a / ARMv8-A). Deprecated and removed legacy 32-bit (armeabi-v7a, x86) and x86_64 target builds.
