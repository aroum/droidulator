# Gruvbox Colors

## Dark Theme

| Variable         | HEX Code  | Original Gruvbox Color | Role / Description                       |
| :--------------- | :-------- | :--------------------- | :--------------------------------------- |
| `s:bg0` (hard)   | `#1d2021` | `dark0_hard`           | Hard (high contrast) background          |
| `s:bg0` (medium) | `#282828` | `dark0`                | Standard background                      |
| `s:bg0` (soft)   | `#32302f` | `dark0_soft`           | Soft background                          |
| `s:bg1`          | `#3c3836` | `dark1`                | Cursor line background, tabs             |
| `s:bg2`          | `#504945` | `dark2`                | Secondary background (menus, status bar) |
| `s:bg3`          | `#665c54` | `dark3`                | Text selection, matching brackets        |
| `s:bg4`          | `#7c6f64` | `dark4`                | Line numbers, separators                 |
| `s:gray`         | `#928374` | `gray_245`             | Gray (comments)                          |
| `s:fg4`          | `#a89984` | `light4`               | Auxiliary text                           |
| `s:fg3`          | `#bdae93` | `light3`               | Secondary text                           |
| `s:fg2`          | `#d5c4a1` | `light2`               | Tertiary text                            |
| `s:fg1`          | `#ebdbb2` | `light1`               | Main text                                |
| `s:fg0`          | `#fbf1c7` | `light0`               | Accent text                              |
| `s:red`          | `#fb4934` | `bright_red`           | Bright red (errors, keywords)            |
| `s:green`        | `#b8bb26` | `bright_green`         | Bright green (strings, functions)        |
| `s:yellow`       | `#fabd2f` | `bright_yellow`        | Bright yellow (data types)               |
| `s:blue`         | `#83a598` | `bright_blue`          | Bright blue (variables)                  |
| `s:purple`       | `#d3869b` | `bright_purple`        | Bright purple (numbers, constants)       |
| `s:aqua`         | `#8ec07c` | `bright_aqua`          | Bright aqua (preprocessor)               |
| `s:orange`       | `#fe8019` | `bright_orange`        | Bright orange (special characters)       |
